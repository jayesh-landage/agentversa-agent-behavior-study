# Usage Note

This repository contains educational analysis of fictional AgentVersa/JusticeNet/LegalVerse simulation scenarios.

Unless a separate license is added, this usage note does not grant an open-source license.

All scenario materials should be handled according to the AgentVersa program's instructions and applicable terms.

Simulated outputs must not be represented as real legal findings, professional legal advice, or proof of misconduct.

A proposed action must not be described as completed unless the simulation explicitly records its completion.

When reusing or quoting this analysis, preserve its context and uncertainty. Claims about NyayaSetu's individual behavior should remain connected to identifiable episode records.

The repository distinguishes original design, predictions, observations, collective simulation reports, and proposed future changes. Missing individual records must be identified transparently rather than reconstructed.
